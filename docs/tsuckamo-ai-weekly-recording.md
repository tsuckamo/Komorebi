# AIから毎週録画を追加・取り消す

「イッテQを毎週録画して」と伝えると、番組表の候補を開きます。録画したい番組と局を選び、検索語、同じ曜日または全曜日、再放送表示の除外を調整してください。「対象を確認」でEPGStationの検索結果を見てから「この条件で毎週録画を登録」を押します。確認前にはルールを作成しません。番組表に開始まで10分以上ある候補が必要です。

選んだ一局の番組名を検索し、開始時刻は固定しません。同じ曜日の時刻変更には番組表を通じて追従します。日付をまたいで別曜日になる変更にも対応したい場合は「全曜日」を選びます。再放送の除外は番組名の再放送表示に基づくため、表示がない再放送まで判別するものではありません。番組名の変更や条件外の放送は対象外です。保存先・録画方式はEPGStationの標準設定を使います。

同じ検索語・局・曜日に重なる既存ルールがあると登録を止めます。無効な既存ルールも含むため、その場合は既存ルールを確認してください。確定直前に番組・検索結果・接続先・重複を再確認し、2分の確認期限を過ぎたり対象が変わったりした場合は登録しません。ルール追加要求はHTTPクライアント内部でも再送しません。

登録後は返されたルールIDを取得して条件を照合します。予約への反映まで確認できた場合と、ルールは保存されたが予約への反映待ちの場合を分けて表示します。通信が切れた場合は登録済みの可能性を案内し、安易な追加登録を避けます。

取り消しは「イッテQの毎週録画をやめて」と伝え、対象ルールと関連予約を確認して確定します。録画済みの番組は残ります。「今週だけ」は自動録画ルールの削除とは異なるため、録画予約一覧から該当回を操作します。[取り消し機能の詳細](tsuckamo-ai-reservation-cancel.md)

AIは検索語だけを提案し、IDや確認トークンを指定しません。毎週録画タグが他の操作タグと混ざっても、確認画面を優先し、単発予約などを同時に実行しません。この確認付き登録はEPGStation接続時に利用できます。

API仕様の確認元: [番組の条件検索](https://github.com/stuayu/EPGStation/blob/main/src/model/service/api/schedules/search.ts)、[ルール追加と返却ID](https://github.com/stuayu/EPGStation/blob/main/src/model/service/api/rules.ts)。
