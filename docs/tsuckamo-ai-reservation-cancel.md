# AIから毎週・自動録画を取り消す

「イッテQの毎週録画をやめて」などと依頼すると、EPGStation上の自動録画ルールを検索します。候補が複数なら選択し、対象ルール・放送局・曜日条件・関連予約を確認して「この毎週予約を取り消す」で確定します。番組名の全半角や記号の違いは候補検索で吸収します。

AIは検索語だけをアプリへ渡します。ルールIDや削除命令、確認トークンはAIから受け取りません。確認トークンは2分で失効し、1回しか使えません。同名の別ルールや別の単発予約は取り消しません。録画済みファイルを削除するAPIも呼びません。

確定直前にルール全体と関連予約を再取得し、確認時から変わっていたら中止します。録画中情報を取得できない場合も中止します。対象の録画中・開始10分以内・終了未反映の予約がある場合は、録画終了後に操作してください。

ルールの削除後は404応答と関連予約の消失を確認してから完了表示を出します。通信切断や反映待ちでは完了扱いにせず、EPGStationのルール・予約一覧での確認を案内します。削除要求は自動再送しません。サーバーに残る特殊な予約（イベントリレーなど）がある場合も、確認できないまま完了とは表示しません。

「今週だけ取り消す」は継続ルールの削除とは異なります。AIからは予約一覧で対象の回を操作するよう案内します。[新規登録にも確認画面があります](tsuckamo-ai-weekly-recording.md)。EPGStation以外のバックエンドには、このAI取り消し機能から変更を送りません。

APIの根拠:
- [ルール削除API](https://github.com/stuayu/EPGStation/blob/main/src/model/service/api/rules/%7BruleId%7D.ts)
- [ルール削除イベントと予約更新](https://github.com/stuayu/EPGStation/blob/main/src/model/event/EventSetter.ts)
- [録画中情報API](https://github.com/stuayu/EPGStation/blob/main/src/model/service/api/recording.ts)

検証は、確認前の書き込み禁止、同名ルールの分離、期限切れ・再利用・接続先変更・番組変更の拒否、録画中保護、失敗時の誤報告防止を中心に行います。
