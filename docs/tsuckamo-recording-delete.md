# EPGStationの録画削除（個人フォーク）

`1.1.1-tsuckamo.1` で、録画リストの無効だった「削除する」をEPGStation接続時に有効化しました。

## 使い方

1. ビデオの録画一覧をリスト表示にします。
2. 対象の番組にフォーカスを合わせ、リモコンの右キーで番組メニューを開きます。
3. 「削除する」を選びます。
4. 番組名・放送局・開始時刻を確認して「録画を削除」を選びます。

確認画面の初期フォーカスは「キャンセル」です。戻るキーでも取り消せます。グリッド表示ではリスト表示に切り替えて操作してください。

## 動作

- `GET /api/recorded/{recordedId}` で直前の状態を確認し、保護中・録画中・エンコード中なら削除しません。
- `DELETE /api/recorded/{recordedId}` で、その録画の情報と紐づくすべての動画ファイル（元TS・エンコード済み）を削除します。動画ファイルIDとは別の録画IDを使います。
- サーバーで成功した後に、端末側の録画キャッシュと視聴履歴を更新します。同期処理と排他制御し、古い同期結果による再登録を防ぎます。
- 処理中は重複操作を抑止します。失敗時は確認画面に理由を表示し、自動で再実行しません。
- KonomiTV・EDCB接続時の削除は引き続き未対応です。

APIの根拠: [stuayu/EPGStationの録画API](https://github.com/stuayu/EPGStation/blob/main/src/model/service/api/recorded/%7BrecordedId%7D.ts)

## 検証

`./gradlew :app:testDebugUnitTest :app:assembleRelease`

`EpgStationRecordingDeletionTest` は模擬HTTPサーバーで、録画IDと動画IDの区別、200/204成功、保護・録画・エンコード中の拒否、不一致ID、事前取得失敗、削除失敗、不正ID、キャンセル伝播を確認します。実サーバーの録画削除はテストに含めません。

2026-10-25: 10件のテストとリリースビルドに成功。TCL Android TVで上書きインストール、起動、削除確認画面の表示、キャンセルへの初期フォーカス、キャンセル後のメニュー復帰を確認しました。実機での録画削除は行っていません。
